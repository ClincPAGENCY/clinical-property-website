# Clinical Property: Website

Specialist healthcare property advisory. Founder: **Nick Alexander**.
Brand system: navy `#0A1F44`, teal `#0096A8`, **DM Sans** (headings) + **Inter** (body).
See `DESIGN.md` for the full, prescriptive brand & typography spec.

## Typography (must match across all collateral)

Per the Brand Identity Brief §03:

- **Headings / display / wordmark: DM Sans** (Google Fonts, free, OFL).
  Page titles **Bold 700**; section headings **SemiBold 600**; tracked caps **Bold 700 +80**.
- **Body / tables / captions: Inter** (Google Fonts, free, OFL).
- **Do NOT use Montserrat, Poppins or Lato**, overexposed in generic real estate /
  wellness branding; they undermine the specialist positioning.

The previous Montserrat version of the site is archived on the `archive/montserrat-version`
branch.
